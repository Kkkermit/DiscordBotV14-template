## What you get

<CardGrid>
  <Card title="Slash and prefix commands" icon="comment">
    Drop a file in a folder and it becomes a command. Cooldowns, permissions, developer-only commands and `/help` are
    built in.
  </Card>
  <Card title="Safe by default" icon="approve-check-circle">
    Your settings are checked on startup with clear messages, broken files are skipped, and errors never crash the bot
    or show users a stack trace.
  </Card>
  <Card title="Optional database" icon="seti:db">
    Add a MongoDB connection string to save data with Mongoose, or leave it empty and the bot runs without one.
  </Card>
  <Card title="Ready to deploy" icon="rocket">
    Run it anywhere Node.js runs, or with Docker. Tests, linting and formatting are set up and run on every push.
  </Card>
</CardGrid>
