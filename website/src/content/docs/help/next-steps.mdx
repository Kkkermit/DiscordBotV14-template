Your bot is running. Here's how to make it do something new.

## Write your first command

<Steps>

1. Create a file at `src/commands/slash/fun/hello.js`. The folder name, `fun`, becomes its category in `/help`.

   ```js title="src/commands/slash/fun/hello.js"
   const { SlashCommandBuilder } = require('discord.js');

   module.exports = {
     data: new SlashCommandBuilder().setName('hello').setDescription('Say hello.'),

     async execute(interaction) {
       await interaction.reply(`Hello, ${interaction.user}!`);
     },
   };
   ```

2. Save it. With `npm run dev` running, the bot restarts by itself. Otherwise, restart it.

3. Type `/hello` in your server.

</Steps>

That's all a command needs: a name, a description and what it does. The bot finds the file, adds it to `/help` and
registers it with Discord.

## Make it yours

- Set `developerName` in `src/config.js` to your name, and pick your prefix, colours and status.
- In `package.json`, change `name`, `description` and `author` to your bot's. The `version` there is your bot's version
  from now on.
- The startup update check tells you about new releases of this template. Once you change `version`, set
  `updateCheck.enabled: false` in `src/config.js`.
